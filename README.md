# เว็บไซต์ Hi-Class EV Car

เว็บใหม่แทน WordPress + Elementor — สร้างด้วย **Next.js 16 + Payload CMS 3** โฮสต์บน **Vercel**
เนื้อหาเก็บใน Supabase project `hiclass-ev-car` schema `cms` (แยกจากตาราง CRM ที่อยู่ใน `public`)

---

## สำหรับทีมการตลาด — แก้เนื้อหาเว็บ

เข้าที่ `https://hiclassevcar.com/admin` แล้วล็อกอิน หลังบ้านเป็นภาษาไทยทั้งหมด

| อยากทำอะไร | ไปที่เมนู |
|---|---|
| เปลี่ยนราคารถ / สเปก / รูป | เนื้อหาเว็บ → **รุ่นรถ** |
| เพิ่ม–ลบโปรโมชัน | เนื้อหาเว็บ → **โปรโมชัน** |
| ลงข่าวหรือกิจกรรม | เนื้อหาเว็บ → **ข่าวสารและกิจกรรม** |
| แก้เบอร์โทร ที่อยู่ ทีมงานสาขา | เนื้อหาเว็บ → **สาขาของเรา** |
| เปลี่ยนดอกเบี้ยที่ใช้คำนวณค่างวด | ตั้งค่าระบบ → **ตั้งค่าเว็บไซต์** → แท็บ *คำนวณค่างวด* |
| เปลี่ยนพาดหัวหน้าแรก | ตั้งค่าระบบ → **ตั้งค่าเว็บไซต์** → แท็บ *หน้าแรก* |

**เรื่องที่ควรรู้**

- กด **Save** แล้วเว็บอัปเดตภายใน 5 นาที
- อัปโหลดรูปใหญ่มาได้เลย ระบบย่อและแปลงเป็น WebP ให้เอง
- โปรโมชันที่ใส่ *สิ้นสุดวันที่* ไว้ จะหายจากเว็บเองเมื่อครบกำหนด ไม่ต้องมาลบ
- ช่อง **ชื่อใน URL** ของรุ่นรถและข่าว — ถ้าเปลี่ยนหลังเว็บขึ้นแล้ว ลิงก์เดิมจะเสียและกระทบอันดับ Google เลี่ยงการแก้
- **แนะนำสาขา** ในหน้าสาขา ต้องเขียนให้ต่างกันจริงทุกสาขา ห้ามคัดลอกข้ามสาขา (เหตุผลอยู่ในแผนหลัก)

## สำหรับผู้ดูแลระบบ — ติดตั้งและ deploy

### รันบนเครื่องตัวเอง

```bash
npm install
cp .env.example .env      # แล้วกรอกค่าให้ครบ
npx payload migrate       # สร้างตารางใน schema cms
npm run seed              # ใส่ข้อมูลตั้งต้น 10 รุ่น + 5 สาขา (รันครั้งเดียว)
npm run dev
```

เปิด http://localhost:3000 และหลังบ้านที่ http://localhost:3000/admin

> `npm run seed` สร้างผู้ใช้ `admin@hiclassevcar.com` / `ChangeMe123!` — **เปลี่ยนรหัสผ่านทันทีหลังล็อกอินครั้งแรก**

### ตัวแปรสภาพแวดล้อม

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `DATABASE_URI` | connection string ของ Supabase (เนื้อหาเว็บ) |
| `PAYLOAD_SECRET` | กุญแจเข้ารหัส session หลังบ้าน — สุ่มใหม่ด้วย `openssl rand -base64 32` |
| `CRM_SUPABASE_URL` | URL ของ Supabase project เดียวกัน สำหรับส่งลีด |
| `CRM_SUPABASE_SERVICE_KEY` | service_role key — **ฝั่งเซิร์ฟเวอร์เท่านั้น** |
| `NEXT_PUBLIC_SITE_URL` | โดเมนจริง ใช้สำหรับ meta tag |

ถ้าไม่ใส่ค่า `CRM_*` ระบบจะบันทึกลีดลง log แทนการเขียนจริง — สะดวกตอนทดสอบ

### deploy ขึ้น Vercel

1. push repo นี้ขึ้น GitHub
2. ที่ Vercel เลือก **Import Project** จาก repo นี้
3. ใส่ Environment Variables ทั้ง 5 ตัวข้างบน
4. Build Command ใช้ค่าเริ่มต้น (`next build`) — ก่อน build ครั้งแรกให้รัน `npx payload migrate` ชี้ไปที่ฐานข้อมูล production หนึ่งครั้ง
5. ผูกโดเมนที่ Vercel แล้วแก้ DNS record ที่ hostatom ให้ชี้มา

> **แผน Vercel** — บัญชีปัจจุบันเป็น Hobby ซึ่งใช้กับเว็บเชิงพาณิชย์ไม่ได้ตามเงื่อนไขการใช้งาน ต้องอัปเกรดเป็น **Pro ($20/เดือน)** ก่อนเปิดใช้จริง

## เรื่องความปลอดภัยที่ห้ามพลาด

ตาราง `crm_leads` ถือข้อมูลลูกค้าทั้งบริษัท เว็บสาธารณะจึงเขียนผ่าน **API ฝั่งเซิร์ฟเวอร์** (`/api/test-drive`) เท่านั้น

- `CRM_SUPABASE_SERVICE_KEY` ห้ามขึ้นต้นด้วย `NEXT_PUBLIC_` และห้าม commit ลง git
- เบราว์เซอร์ของลูกค้าไม่เคยแตะฐานข้อมูลโดยตรง
- มี rate limit 5 ครั้ง / 10 นาที ต่อ IP

## โครงสร้างโปรเจกต์

```
src/
  collections/     รุ่นรถ · โปรโมชัน · ข่าว · สาขา · รูปภาพ · ผู้ใช้
  globals/         ตั้งค่าเว็บไซต์ (พาดหัว เบอร์โทร ดอกเบี้ย)
  components/      ส่วนประกอบหน้าเว็บ
  lib/             crm.ts (ส่งลีด) · data.ts (ดึงเนื้อหา) · types.ts
  migrations/      สคริปต์สร้างตาราง
  scripts/seed.ts  ข้อมูลตั้งต้น
  app/(site)/      หน้าเว็บที่ลูกค้าเห็น
  app/(payload)/   หลังบ้าน
```

## ยังไม่ได้ทำในเฟสนี้

- หน้ารายละเอียดรุ่นรถ `/car-model/[slug]`
- หน้าสาขารายสาขา `/branches/[code]`
- หน้าข่าวรายชิ้น `/news/[slug]`
- ระบบจองคิวศูนย์บริการ (เขียนลง `service_appointments`)
- แจ้งเตือน LINE ตอนมีลีดใหม่ (ต่อกับ `line_settings` ที่มีอยู่)
- multi-tenant สำหรับ 5 โดเมน
- 301 redirect จาก URL เดิมของ WordPress
